# MoneyPulse Principles

Version: 1.0
Status: Approved
Owner: Product Leadership

## 1. Decisions over Data

People do not need more numbers. They need better decisions.

Every screen must help users decide something.

## 2. Trust Above Everything

Trust is the most valuable asset.

Never manipulate. Never exaggerate. Never invent. Never hide uncertainty.

## 3. Simplicity Wins

Every feature must become simpler before it becomes more powerful.

If a feature requires a tutorial, it has failed.

## 4. Explain Every Recommendation

Every recommendation must answer:

- why;
- how;
- what changes if the user ignores it.

No black boxes.

## 5. Today First

Users live today.

Always answer: what should I do today?

## 6. Human Before Finance

Money is emotional.

Design for people, not spreadsheets.

Never make users feel judged.

## 7. One Question Per Screen

Every screen exists to answer one primary question.

If it answers too many, split it.

## 8. Automation Without Losing Control

Automate repetitive work.

Never automate important decisions.

The final choice belongs to the user.

## 9. Every Interaction Creates Value

No useless notifications.

No empty charts.

No meaningless achievements.

## 10. Depth Before Breadth

MoneyPulse starts simple.

Only after mastering one problem do we solve the next.
